# Demo capture checklist

Record a **30–60 second** demo (video or GIF) showing:

1. Creating a research job (Industry: Jewelry Stores, Country: United States,
   Region: California, 100 leads) → Start Research
2. The 8-stage pipeline executing with live counters
3. The results table
4. Filtering (e.g. by state or completeness band) + sorting
5. Opening a record detail view (score breakdown visible)
6. Downloading the Excel export

## How to capture

- Run the app locally: `scripts/dev.sh` (or `docker compose up`).
- Seed first: `make seed-demo`.
- Suggested tools: OBS Studio (video), Peek / ScreenToGif (GIF).
- Keep the browser at 1440×900, hide bookmarks bar.
